# Hive Helsinki - Go & Bash

A collection of programming exercises and projects completed during my Hive Helsinki programming sprint.

The repository contains exercises, CLI applications, and group projects developed while learning and practicing Go and Bash.

## Contents

### Bash

Bash scripting exercises covering:

* File and directory operations
* Navigation and listing
* Text processing
* Searching
* Loops
* File management
* Basic shell scripting

### Go

Go exercises covering:

* Basic operations
* Strings and runes
* Slices and arrays
* Structs
* Iteration and recursion
* Algorithms
* File handling
* CLI applications

### Projects

The repository also includes larger Go projects and group projects, including:

* Cypher Tool
* Notes
* Weather Station
* Wordle
* Green Day Bank

## Project Structure

Projects are organized by sprint day and topic.

Each project may include its own README documenting:

* The objective
* Requirements
* Implementation
* What I practiced

Some exercises currently contain documentation without an implementation. These are kept as references for tasks that I plan to revisit or complete later.
