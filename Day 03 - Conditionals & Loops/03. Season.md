# Season

A simple Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice using `switch` statements to handle multiple cases and return appropriate results for invalid input.

## Task

Create a function named `Season` that takes a month name as a string and returns the corresponding season.

| Season | Months              |
| ------ | ------------------- |
| Winter | `jan`, `feb`, `dec` |
| Spring | `mar`, `apr`, `may` |
| Summer | `jun`, `jul`, `aug` |
| Autumn | `sep`, `oct`, `nov` |

If the input is not a valid month abbreviation, the function returns `"invalid input: "` followed by the original input.

### Example

```go id="f4v8nd"
Season("feb")
// "winter"

Season("September")
// "invalid input: September"
```

## Implementation

The solution is implemented in Go using a `switch` statement.

```go id="s9c2xk"
func Season(month string) string
```
