# Find Dividend

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice loops, conditional logic, divisibility checks, and handling cases where no matching value is found.

## Task

Create a function named `FindDividend` that takes three integers:

* `from` — starting value, inclusive
* `to` — ending value, exclusive
* `divisor` — value used for the divisibility check

The function should return the first number in the range from `from` to `to` that is divisible by `divisor`.

If no such number exists, the function returns `-1`.

### Examples

```go id="q8m2vx"
FindDividend(5, 17, 4)
// 8

FindDividend(10, 18, 9)
// -1
```

## Implementation

The solution is implemented in Go using a loop and the modulo operator.

```go id="k4r7nc"
func FindDividend(from, to, divisor int) int
```

## What I Practiced

* `for` loops
* Conditional logic
* Modulo operations
* Working with ranges
* Finding the first matching value
* Handling cases with no result
* Function parameters and return values
