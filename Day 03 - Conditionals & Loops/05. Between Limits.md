# Between Limits

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with `rune` values, comparing characters, and building strings through iteration.

## Task

Create a function named `BetweenLimits` that takes two runes and returns a string containing all the runes between them in alphabetical order.

The function should work regardless of the order of the input runes.

### Example

```go id="m7q3vn"
BetweenLimits('j', 'f')
// "ghi"
```

The input can also be provided in the opposite order:

```go id="r2x8kc"
BetweenLimits('f', 'j')
// "ghi"
```

## Implementation

The solution is implemented in Go using rune comparisons, iteration, and string construction.

```go id="b5n1wp"
func BetweenLimits(from, to rune) string
```

## What I Practiced

* Working with `rune` values
* Comparing runes
* Handling different input orders
* `for` loops
* Building strings from runes
* Function parameters and return values
