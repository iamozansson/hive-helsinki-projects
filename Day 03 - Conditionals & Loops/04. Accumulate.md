# Accumulate

A simple Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice using loops, conditional statements, and arithmetic operations in Go.

## Task

Create a function named `Accumulate` that takes an integer `n`.

* If `n` is positive, return the sum of all integers from `0` to `n`, including `n`.
* If `n` is negative, return `0`.

### Example

```go id="d8q2mf"
Accumulate(4)
// 10
```

The calculation is:

```text
0 + 1 + 2 + 3 + 4 = 10
```

## Implementation

The solution is implemented in Go using a loop and conditional logic.

```go id="k5v9rp"
func Accumulate(n int) int
```

## What I Practiced

* `for` loops
* Conditional statements
* Integer arithmetic
* Accumulating values
* Handling positive and negative input
* Function parameters and return values
