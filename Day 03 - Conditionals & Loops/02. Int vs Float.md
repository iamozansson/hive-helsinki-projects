# Int vs Float

A simple Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice comparing different numeric types and using conditional logic in Go.

## Task

Create a function named `IntVsFloat` that takes:

* An integer
* A `float32`

The function compares the two values and returns:

* `"Integer"` if the integer is larger
* `"Float"` if the float is larger
* `"Same"` if both values are equal

### Example

```go id="n4d7qp"
IntVsFloat(5, 8.8)
// "Float"
```

## Implementation

The solution is implemented in Go using the following function signature:

```go id="c1h8vk"
func IntVsFloat(i int, f float32) string
```

## What I Practiced

* Comparing different numeric types
* Type conversion
* `if-else` conditional logic
* Comparison operators
* Returning strings from functions
