## Fibonacci

**Learning Objectives:**

* Practice using a loop to compute values where each result depends on the previous two.
* Learn to manage multiple variables across loop iterations to carry state forward.
* Handle edge cases such as n = 0, n = 1, and negative inputs by validating arguments before entering a loop.

### Instructions

Write a function that takes an integer `n` and returns the Fibonacci number at position `n` using a loop. The Fibonacci sequence starts with 0 and 1, and each subsequent number is the sum of the two preceding ones. For any negative input, return 0.

#### Expected function signature

```go id="p7x2m4"
func Fibonacci(n int) int {

}
```

#### Usage

```text id="r3k8w1"

>> 0

Fibonacci(1)
>> 1

Fibonacci(6)
>> 8
```
