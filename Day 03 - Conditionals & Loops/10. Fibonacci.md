# Fibonacci

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice loops, managing state across iterations, and handling edge cases.

## Task

Create a function named `Fibonacci` that returns the Fibonacci number at position `n`.

The Fibonacci sequence starts with `0` and `1`, with each subsequent number being the sum of the previous two numbers.

For negative inputs, the function should return `0`.

### Examples

```text
Fibonacci(0) // 0
Fibonacci(1) // 1
Fibonacci(6) // 8
```

## Implementation

The solution uses a loop and two variables to keep track of the previous Fibonacci values.

Expected function signature:

```go
func Fibonacci(n int) int
```

## What I Practiced

* `for` loops
* Managing state across iterations
* Multiple variables
* Integer arithmetic
* Conditional logic
* Handling edge cases
* Function parameters and return values
