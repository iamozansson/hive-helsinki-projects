# Negative or Not?

A simple Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with integers, boolean values, and conditional logic in Go.

## Task

Create a function named `IsNegative` that takes an integer and returns:

* `true` if the number is negative
* `false` if the number is zero or positive

### Example

```go id="q2m8sz"
IsNegative(6)
// false
```

## Implementation

The solution is implemented in Go using the following function signature:

```go id="x5j3pv"
func IsNegative(n int) bool
```

## What I Practiced

* Working with integers
* Boolean values
* Conditional logic
* Comparison operators
* Function parameters and return values
