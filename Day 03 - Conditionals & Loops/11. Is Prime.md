## Is Prime

**Learning Objectives:**

* Practice using a loop with conditional logic to test a mathematical property of a number.
* Learn to recognise inputs that require special handling before the main logic runs, where the general rule does not apply.

### Instructions

Write a function that takes an integer `n` and returns `true` if `n` is a prime number, and `false` otherwise. A prime number is a natural number greater than 1 that has no divisors other than 1 and itself.

#### Expected function signature

```go id="m8v2q5"
func IsPrime(n int) bool {

}
```

#### Usage

```text id="k4p9s1"
IsPrime(7)
>> true

IsPrime(4)
>> false

IsPrime(1)
>> false
```
