# Is Prime

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice loops, conditional logic, and handling special cases when checking a mathematical property.

## Task

Create a function named `IsPrime` that returns `true` if `n` is a prime number and `false` otherwise.

A prime number is a natural number greater than 1 that has no divisors other than 1 and itself.

### Examples

```text
IsPrime(7) // true
IsPrime(4) // false
IsPrime(1) // false
```

## Implementation

The solution uses conditional logic and a loop to check whether the number has any divisors other than 1 and itself.

Expected function signature:

```go
func IsPrime(n int) bool
```

## What I Practiced

* `for` loops
* Conditional logic
* Modulo operator
* Checking divisibility
* Handling special cases
* Boolean return values
* Function parameters and return values
