# Count Divisible

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice loops, conditional logic, edge-case handling, and divisibility checks in Go.

## Task

Create a function named `CountDivisible` that takes four integers:

* `from` — starting value, inclusive
* `to` — ending value, exclusive
* `step` — interval between values
* `divisor` — value used for the divisibility check

The function should count how many values in the range are divisible by `divisor`.

Return `0` if:

* `step` is zero or negative
* `divisor` is zero

### Example

```go id="w2n6rk"
CountDivisible(5, 17, 2, 3)
// 2
```

The values checked are:

```text id="q8v1sd"
5, 7, 9, 11, 13, 15
```

Among them, `9` and `15` are divisible by `3`.

## Implementation

The solution is implemented in Go using a loop, conditional checks, and the modulo operator.

```go id="m4x7pc"
func CountDivisible(from, to, step, divisor int) int
```
