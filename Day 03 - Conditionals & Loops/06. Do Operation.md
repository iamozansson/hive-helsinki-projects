# Do Operation

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice implementing arithmetic operations, validating input, and handling invalid operations in Go.

## Task

Create a function named `Doop` that takes:

* `a` — an integer
* `op` — an arithmetic operator: `+`, `-`, `/`, `*`, `%`
* `b` — an integer

The function performs the requested operation and returns the result.

For invalid operators or invalid operations, including division or modulo by zero, the function returns `0`.

### Examples

```go id="v8q2lm"
Doop(5, "+", 3)
// 8

Doop(8, "/", 0)
// 0
```

## Implementation

The solution is implemented in Go using conditional logic to handle the supported operators and invalid cases.

```go id="p3w7kd"
func Doop(a int, op string, b int) int
```

## What I Practiced

* Arithmetic operations
* `switch`/conditional logic
* Operator validation
* Handling division by zero
* Handling modulo by zero
* Function parameters and return values
* Input validation
