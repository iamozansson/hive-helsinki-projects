# Shift By

A simple Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with `rune` values and manipulating characters in Go.

## Task

Create a function named `ShiftBy` that takes:

* `r` — a lowercase letter represented as a `rune`
* `step` — the number of positions to shift

The function shifts the letter forward in the alphabet by the specified number of positions and returns the resulting `rune`.

The alphabet should wrap around when the shift goes beyond `z`.

### Example

```go
ShiftBy('a', 4)
// 'e'
```

## Implementation

The solution is implemented in Go using the following function signature:

```go
func ShiftBy(r rune, step int) rune
```

## What I Practiced

* Working with `rune` values
* Rune literals
* Character manipulation
* Arithmetic operations with characters
* Handling alphabet boundaries
* Writing functions with parameters and return values
