# Point Distance

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with `float64` values, mathematical calculations, and the `math` package in Go.

## Task

Create a function named `PointDistance` that takes four `float64` values representing two points on a coordinate plane and returns the Euclidean distance between them.

The calculation uses the distance formula:

```text
d = √((x2 − x1)² + (y2 − y1)²)
```

### Example

```go
PointDistance(0.0, 0.0, 3.0, 4.0)
// 5.0
```

## Implementation

The solution is implemented in Go using the `math` package.

```go
func PointDistance(x1, y1, x2, y2 float64) float64
```

## What I Practiced

* Working with `float64` values
* Arithmetic operations
* Using the `math` package
* Applying the Euclidean distance formula
* Function parameters and return values
