## Point Distance

**Learning Objectives:**

* Use the `math` package for mathematical calculations
* Work with `float64` values and arithmetic operations

### Instructions

Write a function that takes four `float64` values representing two points on a coordinate plane — `x1`, `y1`, `x2`, `y2` — and returns the Euclidean distance between them as a `float64`.

The distance formula is:

```text id="j8zj4v"
d = √((x2 − x1)² + (y2 − y1)²)
```

#### Allowed packages

For this task you're allowed to use:

* `math`

#### Expected function signature

```go id="j4j8jz"
func PointDistance(x1, y1, x2, y2 float64) float64 {

}
```

#### Usage

```text id="n8y8ha"
PointDistance(0.0, 0.0, 3.0, 4.0)
>> 5.0
```
