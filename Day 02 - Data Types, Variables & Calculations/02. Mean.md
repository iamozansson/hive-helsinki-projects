# Mean

A simple Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with functions, `float32` values, and arithmetic operations in Go.

## Task

Create a function named `Mean` that takes three `float32` values and returns their arithmetic mean as a `float32`.

### Example

```go
Mean(1.25, -2.0, 9.75)
// 3.0
```

## Implementation

The solution is implemented in Go using the following function signature:

```go
func Mean(a, b, c float32) float32
```

## What I Practiced

* Defining functions in Go
* Function parameters and return values
* Working with `float32` values
* Arithmetic operations
* Calculating an average
