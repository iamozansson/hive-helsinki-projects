# Reverse Alphabet Value

A simple Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice manipulating characters represented as `rune` values and working with alphabet positions in Go.

## Task

Create a function named `ReverseAlphabetValue` that takes a lowercase letter as a `rune` and returns its corresponding letter from the reverse alphabet.

For example:

* `a` → `z`
* `b` → `y`
* `y` → `b`
* `z` → `a`

The function should preserve the case of the input letter.

### Example

```go id="c6w1ke"
ReverseAlphabetValue('a')
// 'z'
```

## Implementation

The solution is implemented in Go using the following function signature:

```go id="g5d7qr"
func ReverseAlphabetValue(ch rune) rune
```
