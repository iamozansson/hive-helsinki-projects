# Abacus

A simple Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice defining functions in Go, working with parameters and return values, and performing integer arithmetic.

## Task

Create a function named `Abacus` that takes two integers:

* `a` — the dividend
* `b` — the divisor

The function returns the result of integer division.

### Example

```go
Abacus(8, 3)
// 2

Abacus(9, 2)
// 4
```

## Implementation

The solution is implemented in Go using the following function signature:

```go
func Abacus(a int, b int) int
```

## What I Practiced

* Defining functions in Go
* Function parameters and return values
* Variables and integer values
* Integer division
* Testing and debugging Go code
