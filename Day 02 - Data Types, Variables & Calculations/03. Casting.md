# Casting

A simple Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice type conversion and rounding `float64` values to the nearest integer in Go.

## Task

Create a function named `Casting` that:

1. Takes a `float64` value as input
2. Rounds it to the nearest integer
3. Returns the result as an `int`

The `math` package may be used for the rounding operation.

### Example

```go id="e6wq3v"
Casting(1.15)
// 1
```

## Implementation

The solution is implemented in Go using the following function signature:

```go id="q2r8xp"
func Casting(n float64) int
```

## What I Practiced

* Working with `float64` values
* Type conversion
* Rounding numbers
* Using the `math` package
* Function parameters and return values
