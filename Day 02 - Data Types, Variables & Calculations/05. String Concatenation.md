# String Concatenation

A simple Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with strings and combining multiple string values in Go.

## Task

Create a function named `StrConcat` that takes two strings and a delimiter.

The function combines the two strings by placing the delimiter between them and returns the resulting string.

### Example

```go
StrConcat("r", "ProgrammerHumour", "/")
// "r/ProgrammerHumour"
```

## Implementation

The solution is implemented in Go using the following function signature:

```go
func StrConcat(s1, s2, delim string) string
```
