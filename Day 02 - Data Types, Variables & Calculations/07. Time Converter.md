## Time Converter

**Learning Objectives:**

* Use multiple return values in a function
* Apply integer division and modulo operations

### Instructions

Write a function `TimeConverter`. It takes a total number of seconds as an integer and returns the equivalent hours, minutes, and remaining seconds as three separate integers. The function signature is not provided — figuring out the return type is part of the challenge.

#### Usage

```text id="e1t9kg"
TimeConverter(3661)
>> 1, 1, 1

TimeConverter(7384)
>> 2, 3, 4
```
