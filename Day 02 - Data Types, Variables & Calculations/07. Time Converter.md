# Time Converter

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice multiple return values, integer division, and modulo operations in Go.

## Task

Create a function named `TimeConverter` that takes a total number of seconds and converts it into:

* Hours
* Minutes
* Remaining seconds

The function returns all three values as separate integers.

### Example

```go id="t5q9me"
TimeConverter(3661)
// 1, 1, 1

TimeConverter(7384)
// 2, 3, 4
```

## Implementation

The solution is implemented in Go using multiple return values.

## What I Practiced

* Multiple return values
* Integer division
* Modulo operations
* Working with integer values
* Function design in Go
