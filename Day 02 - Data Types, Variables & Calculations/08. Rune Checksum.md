## Rune Checksum

**Learning Objectives:**

* Convert between rune and integer types
* Apply modular arithmetic in a multi-step calculation

### Instructions

Write a function that takes two lowercase runes (from `'a'` to `'l'`) and returns a new rune computed as follows:

1. Convert each rune to its 1-based alphabet position (`'a'` = 1, `'b'` = 2, ..., `'l'` = 12)
2. Multiply the two positions together
3. Take the result modulo 26
4. Convert back to a lowercase rune (`1` = `'a'`, `2` = `'b'`, ..., `26` = `'z'`)

#### Expected function signature

```go
func RuneChecksum(a, b rune) rune {

}
```

#### Usage

```text
RuneChecksum('c', 'd')
>> 'l'
```

`'c'` is position 3, `'d'` is position 4. 3 × 4 = 12. 12 % 26 = 12. Position 12 = `'l'`.
