# Rune Checksum

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice converting between `rune` and integer values and applying modular arithmetic.

## Task

Create a function named `RuneChecksum` that takes two lowercase `rune` values from `a` to `l` and returns a new `rune`.

The calculation follows these steps:

1. Convert each rune to its 1-based alphabet position.
2. Multiply the two positions.
3. Take the result modulo `26`.
4. Convert the result back to a lowercase rune.

### Example

```go
RuneChecksum('c', 'd')
// 'l'
```

`c` = 3 and `d` = 4.

`3 × 4 = 12`, and `12 % 26 = 12`, which corresponds to `l`.

## Implementation

The solution is implemented in Go using the following function signature:

```go
func RuneChecksum(a, b rune) rune
```
