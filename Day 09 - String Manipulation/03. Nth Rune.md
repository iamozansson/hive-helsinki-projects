# Nth Rune

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with strings, runes, and indexes to access a specific character.

## Task

Create a function named `NRune` that takes a non-empty string and an index, then returns the rune at that position.

### Example

```go id="q7m3vx"
NRune("Coding is cool", 4)
// 'n'
```

## Implementation

The solution converts the string into a rune slice and returns the rune at the specified index.

Expected signature:

```go id="k5r9wp"
func NRune(s string, i int) rune
```

## What I Practiced

* Strings and runes
* Rune slices
* Indexing
* Character extraction
* Unicode-aware string handling
* Function parameters and return values
