# Lower or Not?

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice validating string contents and using conditional logic to return a boolean result.

## Task

Create a function named `IsLower` that returns `true` if a string contains only lowercase characters and `false` otherwise.

### Examples

```go id="p4x8mv"
IsLower("hello")
// true

IsLower("world!")
// false
```

## Implementation

The solution checks each character in the string and verifies that it is a lowercase letter.

Expected signature:

```go id="n7q2wr"
func IsLower(s string) bool
```
