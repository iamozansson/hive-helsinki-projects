# Get Last Rune

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with strings and runes while extracting a character from the end of a string.

## Task

Create a function named `GetLastRune` that takes a non-empty string and returns its last character as a `rune`.

### Example

```go id="p6x2nz"
GetLastRune("kood")
// 'd'
```

## Implementation

The solution converts the string to a rune slice and returns the last rune.

Expected signature:

```go id="m9q4vk"
func GetLastRune(s string) rune
```

## What I Practiced

* Strings and runes
* Rune slices
* Character extraction
* Working with Unicode characters
* Function parameters and return values
