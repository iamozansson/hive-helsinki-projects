# To Capital Case

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice manipulating strings and applying capitalization rules to individual words.

## Task

Create a function named `ToCapitalCase` that capitalizes the first letter of each word and converts the remaining letters to lowercase.

A word is defined as a sequence of alphanumeric characters.

### Example

```go id="m7x4qn"
ToCapitalCase("Hello! Great to see you! How-are-you-doing-2day?")
// "Hello! Great To See You! How-Are-You-Doing-2day?"
```

## Implementation

The solution processes the string character by character, identifies word boundaries, capitalizes the first character of each word, and converts the remaining letters to lowercase.

Expected signature:

```go id="r5k2vw"
func ToCapitalCase(s string) string
```
