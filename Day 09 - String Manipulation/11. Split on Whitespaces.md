# Split on Whitespaces

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice parsing strings and splitting text into words based on different whitespace characters.

## Task

Create a function named `SplitWhitespaces` that splits a string into words using spaces, tabs, and newlines as separators.

The resulting words should be returned as a slice of strings.

### Example

```go id="m4x8qp"
SplitWhitespaces("Hello! How have you been?")
// []string{"Hello!", "How", "have", "you", "been?"}
```

## Implementation

The solution processes the string and identifies spaces, tabs, and newlines as word separators, then stores the resulting words in a new slice.

Expected signature:

```go id="r7k2vn"
func SplitWhitespaces(s string) []string
```
