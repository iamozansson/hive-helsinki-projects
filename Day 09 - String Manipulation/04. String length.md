# Str Length

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with strings, runes, bytes, and UTF-8 encoding.

## Task

Create a function named `StrLength` that returns two values in a slice:

* The number of runes in the string
* The number of bytes in the string

The function should correctly handle UTF-8 encoded characters.

### Example

```go id="f4m8qx"
StrLength("Hello World!")
// []int{12, 12}
```

## Implementation

The solution counts the number of runes separately from the byte length of the original string, allowing the two values to differ when the string contains multi-byte UTF-8 characters.

Expected signature:

```go id="z6k2vp"
func StrLength(s string) []int
```
