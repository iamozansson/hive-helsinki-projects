# Number to Base

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice number representation, base conversion, input validation, and string construction.

## Task

Create a function named `NbrBase` that converts an integer to its representation in a specified base.

The base must:

* Contain at least 2 unique characters
* Not contain `+` or `-`
* Contain no duplicate characters

Negative numbers should be supported. If the base is invalid, the function should return `"NV"`.

### Examples

```go id="m7x4qn"
NbrBase(92, "0123456789")
// "92"

NbrBase(-92, "01")
// "-1011100"

NbrBase(92, "0123456789ABCDEF")
// "5C"

NbrBase(-92, "coding")
// "-did"

NbrBase(92, "abb")
// "NV"
```

## Implementation

The solution first validates the base, then repeatedly divides the number by the base length and uses the remainder to determine each digit. The resulting digits are assembled in reverse order, with a `-` prefix added for negative numbers.

Expected signature:

```go id="r8k2vw"
func NbrBase(n int, base string) string
```
