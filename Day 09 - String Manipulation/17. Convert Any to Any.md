# Convert Any to Any

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice converting numbers between different bases using the positional number system.

## Task

Create a function named `ConvertAnyToAny` that converts a number from one base to another.

The function takes:

* `nbr` — the number to convert
* `baseFrom` — the base of the input number
* `baseTo` — the target base

### Example

```text
ConvertAnyToAny("100001", "01", "0123456789")
// "33"
```

## Implementation

The solution first converts the input number from `baseFrom` to its decimal value, then converts that value into `baseTo`.

Expected signature:

```go
func ConvertAnyToAny(nbr, baseFrom, baseTo string) string
```
