# Str Reverse

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice manipulating strings and reversing their content.

## Task

Create a function named `StrReverse` that takes a string and returns its reversed version.

### Example

```go id="v7m2qx"
StrReverse("Hello Coder!")
// "!redoC olleH"
```

## Implementation

The solution reverses the string character by character and returns the resulting string.

Expected signature:

```go id="k4p9nw"
func StrReverse(s string) string
```
