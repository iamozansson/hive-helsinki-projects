# Str Split By

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice parsing strings and splitting text using a custom separator.

## Task

Create a function named `StrSplitBy` that splits a string into substrings using the provided separator.

The resulting substrings should be returned as a slice of strings.

### Example

```go id="m7x3qp"
s := "HowYOUhaveYOUyouYOUbeen?"

StrSplitBy(s, "YOU")
// []string{"How", "have", "you", "been?"}
```

## Implementation

The solution searches for occurrences of the separator, extracts the text between them, and stores the resulting substrings in a new slice.

Expected signature:

```go id="r4n8vw"
func StrSplitBy(s, sep string) []string
```
