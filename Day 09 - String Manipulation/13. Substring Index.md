# Substring Index

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice searching within strings, working with indexes, and handling cases where a substring is not found.

## Task

Create a function named `SubstrIndex` that finds the index of the first occurrence of `toFind` in `s`.

If `toFind` is not present in `s`, the function should return `-1`.

### Examples

```go id="v8q3mk"
SubstrIndex("How are you?", "o")
// 1

SubstrIndex("How are you doing?", "ou")
// 9

SubstrIndex("You can do it!", " od")
// -1
```

## Implementation

The solution searches through the string for the first occurrence of the target substring and returns its index. If no match is found, it returns `-1`.

Expected signature:

```go id="n6r2wp"
func SubstrIndex(s string, toFind string) int
```
