# Numeric or Not?

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice validating string contents and using conditional logic to return a boolean result.

## Task

Create a function named `IsNumeric` that returns `true` if a string contains only numeric characters and `false` otherwise.

### Examples

```go id="m7x2qp"
IsNumeric("012345")
// true

IsNumeric("01+23-45")
// false
```

## Implementation

The solution checks each character in the string and verifies that it is a numeric digit.

Expected signature:

```go id="k4n8vw"
func IsNumeric(s string) bool
```
