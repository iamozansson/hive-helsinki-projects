# Convert Any to Decimal

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice converting numbers from different bases to decimal and validating custom base definitions.

## Task

Create a function named `ConvertAnyToDec` that converts a numeric string from a specified base to its decimal integer value.

The base must:

* Contain at least 2 unique characters
* Not contain `+` or `-`
* Contain only unique characters

The input string is assumed to be a valid number using characters from the base. Negative numbers are not supported.

If the base is invalid, the function should return `0`.

### Examples

```go id="m7x4qn"
ConvertAnyToDec("92", "0123456789")
// 92

ConvertAnyToDec("1011100", "01")
// 92

ConvertAnyToDec("5C", "0123456789ABCDEF")
// 92

ConvertAnyToDec("did", "coding")
// 92

ConvertAnyToDec("bbbac", "-abc")
// 0
```

## Implementation

The solution validates the base first, then processes each character of the input from left to right. Each character is converted to its corresponding digit value in the base and combined using positional base arithmetic.

Expected signature:

```go id="r8k2vw"
func ConvertAnyToDec(s string, base string) int
```
