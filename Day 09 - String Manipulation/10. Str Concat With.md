# Str Concat With

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice combining strings from a slice using a custom separator.

## Task

Create a function named `StrConcatWith` that concatenates all strings in a slice and places the provided separator between each element.

### Example

```go id="q6m8vx"
toConcat := []string{"Three", " Two", " One", " Go!"}

StrConcatWith(toConcat, ".")
// "Three. Two. One. Go!"
```

## Implementation

The solution iterates through the slice, adds each string to the result, and inserts the separator between consecutive elements.

Expected signature:

```go id="n4r7wp"
func StrConcatWith(strs []string, sep string) string
```
