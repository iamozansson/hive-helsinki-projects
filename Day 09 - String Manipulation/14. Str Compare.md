# Str Compare

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice comparing strings and implementing lexicographic ordering.

## Task

Create a function named `StrCompare` that compares two strings and returns:

* `0` if the strings are equal
* `-1` if `a` comes before `b` lexicographically
* `1` if `a` comes after `b` lexicographically

### Examples

```go id="m7x4qn"
StrCompare("Hi!", "Hi!")
// 0

StrCompare("Day", "ay")
// -1

StrCompare("weekday", "week")
// 1
```
