# To Upper Case

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice manipulating strings and converting letters to uppercase.

## Task

Create a function named `ToUpperCase` that takes a string and returns a new string with each letter converted to uppercase.

### Example

```go id="m8q4vx"
ToUpperCase("Hello! How's your day going?")
// "HELLO! HOW'S YOUR DAY GOING?"
```

## Implementation

The solution iterates through the string, converts lowercase letters to uppercase, and preserves non-letter characters.

Expected signature:

```go id="k3r7wp"
func ToUpperCase(s string) string
```
