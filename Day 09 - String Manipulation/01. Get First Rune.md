# Get First Rune

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with strings and converting character data to a `rune`.

## Task

Create a function named `GetFirstRune` that takes a non-empty string and returns its first character as a `rune`.

### Example

```go id="n4k7px"
GetFirstRune("kood")
// 'k'
```

## Implementation

The solution accesses the first rune of the string and returns it.

Expected signature:

```go id="w6q2mv"
func GetFirstRune(s string) rune
```

## What I Practiced

* Strings and runes
* Type conversion
* String indexing
* Character extraction
* Function parameters and return values
