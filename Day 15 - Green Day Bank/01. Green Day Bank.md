# Green Day Bank

In this project you are tasked with creating a simple command-line banking application in Go.

Users can log in, manage their money, send money to other users, invest in funds, and manage their accounts.

## Functional Requirements

### User Interaction

The application must use **`bufio.Scanner`** from the `bufio` package for all user input.

The program must handle **EOF (Ctrl+D)** gracefully by breaking out of input loops when:

```go
scanner.Scan()
```

returns `false`.

Invalid input should be handled gracefully with appropriate error messages.

### Login System

The application supports four users:

```text
Alice
Bob
Charlie
Diana
```

Users must log in by entering their name.

All four users can send money to each other.

### Menu System

After logging in, the following menu must be displayed in this exact order:

```text
 --- Banking App Menu ---
1. Show balance
2. Deposit money
3. Withdraw money
4. Send money to a person
5. Invest in funds
6. Transfer between accounts
7. Withdraw all investments
8. Logout
9. Exit
```

The user selects an option by entering its corresponding number.

After each operation, the menu should be displayed again.

## Account Management

Each user starts with:

```text
$1000 cash
```

This money is **not deposited** initially.

Each user has two accounts:

* Savings account
* Investment account

Both accounts initially have a balance of zero.

All account balances must use:

```go
decimal.Decimal
```

from the `shopspring/decimal` package.

### Savings Account

The bank provides **1% interest** on savings.

Every time the user views their balance, the 1% interest is calculated and added to the savings balance.

Users can:

* Deposit money from cash into savings.
* Withdraw money from savings back to cash.
* Send money from savings to another user.
* Transfer money between savings and investment accounts.

### Investment Account

Users can transfer money into their investment account and invest that money in predefined funds.

The available funds are:

```text
LOW_RISK      → 2%
MEDIUM_RISK   → 5%
HIGH_RISK     → 10%
```

The gain is calculated and added to the fund every time the user views their account balance.

Users can withdraw all investments at any time.

When investments are withdrawn, all fund money is moved back into the investment account balance.

## Session Management

Once a user logs in, their session remains active until they:

* Log out.
* Exit the application.

### Logout

The current user is logged out and another user can log in.

### Exit

The application terminates.

## Technical Implementation

`main.go` must be located at the **root** of the repository.

The repository name and Go module name should be:

```text
simpleBank
```

The application entry point should be:

```text
simpleBank
├── main.go
├── model/
│   ├── account.go
│   ├── fund.go
│   ├── investment_account.go
│   ├── savings_account.go
│   └── user.go
└── service/
    └── banking_service.go
```

This structure is only an example. You may organize the code differently as long as the required functionality works correctly.

## Important Requirements

Make sure the application:

* Uses `bufio.Scanner` for user input.
* Handles EOF without crashing.
* Supports all four users.
* Starts every user with $1000 cash.
* Uses `decimal.Decimal` for financial values.
* Applies 1% savings interest when viewing the balance.
* Supports deposits and withdrawals.
* Supports sending money between users.
* Supports transfers between savings and investment accounts.
* Supports all three investment funds.
* Applies the correct fund appreciation.
* Supports withdrawing all investments.
* Supports login, logout, and exit.
* Handles invalid usernames and insufficient funds gracefully.
