# Bulk Atoi

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice applying a function to multiple values in a slice and composing functionality from a previous exercise.

## Task

Create a function named `BulkAtoi` that takes a slice of strings, converts each element to an integer using the `StrToInt` logic, and returns the results as a new slice.

Invalid strings should be converted to `0`.

### Example

```go
BulkAtoi([]string{"8", "kood", "-13"})
// [8 0 -13]
```

## Implementation

The solution iterates through the input slice, applies the `StrToInt` logic to each string, and stores the resulting integers in a new slice.

Expected signature:

```go
func BulkAtoi(arr []string) []int
```

## What I Practiced

* Slice manipulation
* Iterating over slices
* Function composition
* String-to-integer conversion
* Creating and populating a new slice
* Function parameters and return values
