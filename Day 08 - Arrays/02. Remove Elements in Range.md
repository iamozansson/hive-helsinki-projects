# Remove Elements in Range

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice slice manipulation, index handling, and dealing with edge cases such as negative or out-of-bounds indices.

## Task

Create a function named `RemoveElementsInRange` that removes elements from a `float64` slice within a specified index range.

The range should:

* Remove the element at the lower index
* Keep the element at the upper index
* Work when the indices are provided in either order
* Handle negative indices
* Handle indices larger than the slice length

### Example

```text id="p5v8rm"
RemoveElementsInRange(
    []float64{10., .8, -.4, 20., 7.7, 3.},
    4,
    1,
) // [10 7.7 3]
```

## Implementation

The solution handles the index boundaries and order before removing the selected range from the slice.

Expected function signature:

```go id="k3n7wx"
func RemoveElementsInRange(arr []float64, from, to int) []float64
```
