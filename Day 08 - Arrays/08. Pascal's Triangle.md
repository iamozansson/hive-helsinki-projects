## Pascal's Triangle

**Learning Objectives:**

* Gain practical experience working with 2D slices by building and populating a triangular structure.
* Practice using nested loops to calculate values based on previously computed rows.
* Understand how to allocate slices of varying lengths within a 2D slice.
* Apply mathematical pattern recognition to implement an algorithm that builds on prior results.

### Instructions

Write a function that takes a positive integer `n` and returns a 2D integer slice representing the first `n` rows of [**Pascal's triangle**](https://www.mathsisfun.com/pascals-triangle.html). In Pascal's triangle, the first and last element of every row is `1`, and every other element is the sum of the two elements directly above it. If `n` is less than or equal to `0`, the function should return nil.

#### Expected function signature

```go id="q8v3mw"
func PascalsTriangle(n int) [][]int {

}
```

#### Usage

```text id="r5k7xp"
PascalsTriangle(1)
>> [[1]]

PascalsTriangle(5)
>> [[1] [1 1] [1 2 1] [1 3 3 1] [1 4 6 4 1]]
```
