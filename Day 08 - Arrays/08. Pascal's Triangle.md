# Pascal's Triangle

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice working with 2D slices, nested loops, and building a data structure based on previously calculated values.

## Task

Create a function named `PascalsTriangle` that returns the first `n` rows of Pascal's triangle.

The first and last element of each row is always `1`. The other elements are calculated by adding the two values directly above them.

For `n <= 0`, the function should return `nil`.

### Examples

```go id="8ajm1p"
PascalsTriangle(1)
// [[1]]

PascalsTriangle(5)
// [[1] [1 1] [1 2 1] [1 3 3 1] [1 4 6 4 1]]
```

## Implementation

The solution builds the triangle row by row. Each row is created with the required length, with the first and last elements set to `1`. The values in between are calculated using the two elements from the previous row.

Expected signature:

```go id="x7q2vn"
func PascalsTriangle(n int) [][]int
```

## What I Practiced

* 2D slices
* Nested loops
* Creating slices with different lengths
* Accessing previous rows
* Calculating values from existing data
* Conditional logic
* Function parameters and return values
