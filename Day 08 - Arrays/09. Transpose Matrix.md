# Transpose Matrix

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice working with 2D slices, nested loops, and transforming matrix dimensions.

## Task

Create a function named `TransposeMatrix` that returns the transpose of a given matrix.

Transposing a matrix swaps its rows and columns, so the element at position `[i][j]` moves to `[j][i]`.

The function must also handle non-square matrices. An empty or nil input should return `nil`.

### Examples

```go id="x8w4kj"
TransposeMatrix([][]int{{1, 2, 3}, {4, 5, 6}})
// [[1 4] [2 5] [3 6]]

TransposeMatrix([][]int{{1, 2}, {3, 4}, {5, 6}})
// [[1 3 5] [2 4 6]]
```

## Implementation

The solution creates a new 2D slice with swapped dimensions and uses nested loops to move each element from `[i][j]` to `[j][i]`.

Expected signature:

```go id="m2v7qn"
func TransposeMatrix(matrix [][]int) [][]int
```

## What I Practiced

* 2D slices
* Nested loops
