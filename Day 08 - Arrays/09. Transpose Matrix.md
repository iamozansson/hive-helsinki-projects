## Transpose Matrix

**Learning Objectives:**

* Gain practical experience working with 2D arrays and understanding how rows and columns relate to each other.
* Practice using nested loops to iterate over and transform structured data.
* Understand how to allocate and populate a 2D array with the correct dimensions.
* Learn to handle non-square matrices where the number of rows and columns differ.

### Instructions

Write a function that takes a matrix represented as a 2D array and returns the transposed matrix. Transposing a matrix means swapping its rows and columns: element at position `[i][j]` moves to position `[j][i]` in the result. The function must handle non-square matrices. An empty or nil input should return nil.

### Expected function signature

```go id="q6v9mx"
func TransposeMatrix(matrix [][]int) [][]int {

}
```

### Usage

```text id="r2k7wp"
TransposeMatrix([][]int{{1, 2, 3}, {4, 5, 6}})
>> [[1 4] [2 5] [3 6]]

TransposeMatrix([][]int{{1, 2}, {3, 4}, {5, 6}})
>> [[1 3 5] [2 4 6]]
```
