# Balance Out

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with boolean values, counting elements, and modifying slices while preserving their original order.

## Task

Create a function named `BalanceOut` that adds the minimum number of boolean values needed to make the number of `true` and `false` values equal.

The function should:

* Keep the original elements in the same order
* Add new elements only at the end of the slice
* Add only the minimum number of values required

### Example

```text
BalanceOut([]bool{true, false, false, false})
// [true false false false true true]
```

## Implementation

The solution counts the number of `true` and `false` values, determines the difference between them, and appends the required boolean values to the slice.

Expected function signature:

```go
func BalanceOut(arr []bool) []bool
```
