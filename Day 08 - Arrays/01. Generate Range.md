# Least Common Multiple

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice loops, conditional logic, and reusing a previously implemented algorithm to solve a related problem.

## Task

Create a function named `LCM` that takes two integers and returns their least common multiple (LCM).

The LCM is the smallest positive integer that is divisible by both input values.

If either input is `0` or the LCM does not exist, the function should return `0`.

### Example

```text id="q6n3wp"
LCM(12, 18) // 36
```

## Implementation

The solution uses the previously implemented `GCD` function to calculate the least common multiple.

Expected function signature:

```go id="z8m4kx"
func LCM(a, b int) int
```

## What I Practiced

* Conditional logic
* Loops
* Integer arithmetic
* Reusing functions
* Working with GCD and LCM
* Handling zero values
* Function parameters and return values
