# Filter by Sum

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with nested slices, loops, conditional logic, and filtering data based on a calculated value.

## Task

Create a function named `FilterBySum` that takes a 2D slice of integers and a `limit` value.

The function should remove all sub-slices whose elements have a sum lower than `limit`.

The remaining sub-slices should be returned in their original order.

### Example

```text id="q4m8vx"
FilterBySum([][]int{{1, 2, 3}, {2, 3, 4}, {3, 4, 5}}, 9)
// [[2 3 4] [3 4 5]]
```

## Implementation

The solution iterates through each sub-slice, calculates its sum, and appends it to the result only when the sum meets the required limit.

Expected function signature:

```go id="n7p3kc"
func FilterBySum(arr [][]int, limit int) [][]int
```
