# Remove Duplicates

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice iterating over slices, detecting duplicate values, and building a new slice while preserving the original order.

## Task

Create a function named `RemoveDuplicates` that removes duplicate values from a slice of integers.

Only the first occurrence of each value should be kept, and the order of the remaining elements must stay unchanged.

An empty or nil input should return `nil`.

### Examples

```go id="v5n8qx"
RemoveDuplicates([]int{3, 5, 2, 3, 8, 5, 2})
// [3 5 2 8]

RemoveDuplicates([]int{1, 2, 3, 2, 4, 8, 8, 1, 2, 0, 8})
// [1 2 3 4 8 0]

RemoveDuplicates(nil)
// nil
```

## Implementation

The solution iterates through the input slice and checks whether each value has already been added to the result. If it has not, the value is appended while preserving the original order.

Expected signature:

```go id="p2m7kr"
func RemoveDuplicates(arr []int) []int
```

## What I Practiced

* Slice iteration
* Nested loops
* Comparing values
* Detecting duplicates
* Building a new slice
* Preserving element order
* Handling nil and empty input
