## Remove Duplicates

**Learning Objectives:**

* Practice iterating over arrays and comparing elements using nested loops.
* Learn to build a new array by selectively appending elements based on a condition.
* Understand how to preserve the original order of elements while filtering data.

### Instructions

Write a function that takes an array of integers and returns a new array with all duplicate values removed, keeping only the first occurrence of each value. The order of the remaining elements must be the same as in the input. An empty or nil input should return nil.

#### Expected function signature

```go id="x4p8kn"
func RemoveDuplicates(arr []int) []int {

}
```

#### Usage

```text id="m7q2vz"
RemoveDuplicates([]int{3, 5, 2, 3, 8, 5, 2})
>> [3 5 2 8]

RemoveDuplicates([]int{1, 2, 3, 2, 4, 8, 8, 1, 2, 0, 8})
>> [1 2 3 4 8 0]

RemoveDuplicates(nil)
>> nil
```
