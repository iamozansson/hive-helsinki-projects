# Sort Integers

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice sorting data and modifying a slice in place.

## Task

Create a function named `SortIntegerTable` that sorts a slice of integers in ascending order.

### Example

```go
SortIntegerTable([]int{2, 0, 5, 4, 1, 3})
// [0 1 2 3 4 5]
```

## Implementation

The solution sorts the elements of the slice in ascending order and returns the sorted slice.

Expected signature:

```go
func SortIntegerTable(table []int) []int
```

## What I Practiced

* Slice manipulation
* Sorting integers
* Loops and comparisons
* Modifying data in place
* Function parameters and return values
