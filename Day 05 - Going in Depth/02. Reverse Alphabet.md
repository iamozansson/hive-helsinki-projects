# Reverse Alphabet

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice loops, conditional logic, and generating a sequence based on an input step value.

## Task

Create a function named `ReverseAlphabet` that starts from `z` and generates a sequence of lowercase letters in reverse alphabetical order.

The `step` value determines how many letters are skipped between each selected letter. If `step` is `0` or negative, the default value of `1` should be used.

### Example

```text
ReverseAlphabet(5) // "zupkfa"
```

## Implementation

The solution uses a loop to move backwards through the alphabet according to the given step value.

Expected function signature:

```go
func ReverseAlphabet(step int) string
```
