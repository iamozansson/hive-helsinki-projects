# Alphabet Mastery

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice loops, string construction, and working with characters to generate a sequence of letters.

## Task

Create a function named `AlphabetMastery` that takes a positive integer `n` and returns the first `n` letters of the Latin alphabet.

The input will not be larger than the length of the alphabet.

### Example

```text
AlphabetMastery(6) // "abcdef"
```

## Implementation

The solution uses a loop to generate the required letters and builds the result as a string.

Expected function signature:

```go
func AlphabetMastery(n int) string
```

## What I Practiced

* `for` loops
* Strings
* String construction
* Character and rune handling
* Working with indexes
* Function parameters and return values
