# Pairs

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice nested loops, string formatting, and generating combinations of values in a specific order.

## Task

Create a function named `Pairs` that generates all possible combinations of two two-digit numbers.

The pairs should:

* Be in ascending order
* Contain two numbers from `00` to `99`
* Use a leading zero for numbers below `10`
* Separate the two numbers with a space
* Separate each pair with a comma and a space

### Example

```text
Pairs() // "00 01, 00 02, 00 03, ..., 98 99"
```

## Implementation

The solution uses nested loops to generate the pairs in ascending order and `fmt` for formatting the numbers and output string.

Expected function signature:

```go
func Pairs() string
```

The `fmt` package is the only allowed package for this exercise.

## What I Practiced

* Nested `for` loops
* Generating combinations
* String construction
* Number formatting
* Zero-padding
* Maintaining ascending order
* Using the `fmt` package
