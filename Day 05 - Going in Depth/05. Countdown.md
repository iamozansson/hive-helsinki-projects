# Countdown

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice loops, string construction, and conditional logic while generating a sequence of numbers.

## Task

Create a function named `Countdown` that takes a one-digit integer and returns a countdown string.

The countdown should:

* Start from the given number
* Decrease by 2 each step
* End with `0!`
* Separate the numbers with a comma and a space

### Example

```text id="u7k2px"
Countdown(7) // "7, 5, 3, 1, 0!"
```

## Implementation

The solution uses a loop to generate the countdown and builds the result as a string.

Expected function signature:

```go id="v4m8rs"
func Countdown(n int) string
```

## What I Practiced

* `for` loops
* Conditional logic
* String construction
* Working with integer values
* Decrementing values by a fixed step
* Function parameters and return values
