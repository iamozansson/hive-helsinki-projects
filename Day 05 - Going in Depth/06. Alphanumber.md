# Alphanumber

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice type conversion, string manipulation, character mapping, and handling negative numbers.

## Task

Create a function named `AlphaNumber` that converts an integer into a string by replacing each digit with its corresponding lowercase letter.

The mapping is:

* `0` → `a`
* `1` → `b`
* `2` → `c`
* ...
* `9` → `j`

For negative numbers, the minus sign should be preserved.

### Example

```text
AlphaNumber(-1280) // "-bcia"
```

## Implementation

The solution converts the integer into a string and maps each digit to its corresponding letter while preserving the minus sign when necessary.

Expected function signature:

```go
func AlphaNumber(n int) string
```
