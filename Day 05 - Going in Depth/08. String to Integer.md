# String to Integer

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice string parsing, integer conversion, sign handling, and input validation.

## Task

Create a function named `StrToInt` that mimics the basic behavior of Go's `Atoi` function.

The function should:

* Convert a valid numeric string into an integer
* Support `+` and `-` signs
* Return `0` for invalid input
* Return `0` when the input contains multiple signs or non-numeric characters

The exercise does not require returning an error.

### Examples

```text id="g3x8kp"
StrToInt("10203")        // 10203
StrToInt("0000000010203") // 10203
StrToInt("010 203")      // 0
StrToInt("Hello World!") // 0
StrToInt("+10203")       // 10203
StrToInt("-10203")       // -10203
StrToInt("++10203")      // 0
StrToInt("--10203")      // 0
```

## Implementation

The solution validates the input string, handles an optional sign, and converts the remaining digits into an integer.

Expected function signature:

```go id="w7n2mc"
func StrToInt(s string) int
```
