# Simple String to Integer

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice converting strings to integers, validating input, and processing individual characters.

## Task

Create a function named `SimpleStrToInt` that converts a valid string representation of a number into an integer.

If the string is not a valid number, the function should return `0`.

The input contains one or more digits and does not include `+` or `-` signs.

### Examples

```text id="m5r8qn"
SimpleStrToInt("10203")       // 10203
SimpleStrToInt("0000000010203") // 10203
```

## Implementation

The solution processes the characters in the input string, validates that they are digits, and builds the resulting integer.

Expected function signature:

```go id="x2k7vp"
func SimpleStrToInt(s string) int
```

* Converting characters to integers
