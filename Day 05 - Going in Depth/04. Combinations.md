# Combinations

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice nested loops, generating combinations, applying conditions, and formatting strings.

## Task

Create a function named `Combinations` that generates all unique triplets of digits in ascending order.

Each triplet must:

* Contain three different digits
* Be ordered from smallest to largest
* Be separated from the next triplet by a comma and a space

For example, valid combinations include `012`, `013`, and `789`. Combinations such as `000` or `987` are excluded.

### Example

```text id="x8p2kd"
Combinations() // "012, 013, ..., 689, 789"
```

## Implementation

The solution uses nested loops to generate the digits and conditions to ensure that each triplet contains unique digits in ascending order.

The `fmt` package is the only allowed package for this exercise.

Expected function signature:

```go id="c5m9vq"
func Combinations() string
```

## What I Practiced

* Nested `for` loops
* Generating combinations
* Conditional logic
* Comparing values
* String construction
* Formatting output
* Using the `fmt` package
