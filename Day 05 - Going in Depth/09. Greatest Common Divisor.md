# Greatest Common Divisor

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice loops, numerical operations, and reducing a problem step by step to find a result.

## Task

Create a function named `GCD` that takes two integers and returns their greatest common divisor (GCD).

The GCD is the largest positive integer that divides both input values without leaving a remainder.

### Example

```text id="k7v2mx"
GCD(12, 18) // 6
```

## Implementation

The solution uses a loop and repeated numerical operations to determine the greatest common divisor.

Expected function signature:

```go id="p4n8qs"
func GCD(a, b int) int
```

## What I Practiced

* `for` loops
* Modulo operation
* Integer arithmetic
* Reducing a problem step by step
* Function parameters and return values
* Algorithmic problem solving
