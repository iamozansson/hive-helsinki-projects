## Least Common Multiple

**Learning Objectives:**

* Implementing the LCM algorithm reinforces your understanding of conditional statements and loops.
* Understanding how LCM can be derived from the GCD algorithm.
* Reusing previously implemented code in the solution.

### Instructions

Write a Go function that takes two integers as input and returns their least common multiple (LCM). The LCM is the smallest positive integer that is divisible by both of the input integers. If the LCM doesn't exist or either input is 0, return 0.

### Expected function signature

```go id="j4n8px"
func LCM(a, b int) int {

}
```

### Usage

```text id="c7m2qw"
LCM(12, 18)
>> 36
```
