# Factorial Iterative

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice solving mathematical problems using iterative functions and handling invalid values and integer overflows.

## Task

Create a function named `FactorialIterative` that calculates the factorial of a given integer.

The function should return `0` for negative values or when the result would overflow an `int`.

### Example

```text id="n6p4xk"
FactorialIterative(5)
// 120
```

## Implementation

The solution uses a loop to multiply the values from `1` to `n`. It also checks for invalid input and potential integer overflow before performing each multiplication.

Expected signature:

```go id="h8r2qm"
func FactorialIterative(n int) int
```
