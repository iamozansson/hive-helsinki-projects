# To the Power Iterative

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice using iteration to calculate the power of an integer.

## Task

Create a function named `ToThePowerIterative` that calculates `n` raised to the given `power`.

For negative powers, the function should return `0`.

### Example

```text id="f5k2qp"
ToThePowerIterative(2, 10)
// 1024
```

## Implementation

The solution uses a loop to repeatedly multiply `n` by itself according to the given power.

Expected signature:

```go id="r7m3vx"
func ToThePowerIterative(n int, power int) int
```
