# To the Power Recursive

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice recursion by calculating the power of an integer without using loops.

## Task

Create a recursive function named `ToThePowerRecursive` that calculates `n` raised to the given `power`.

For negative powers, the function should return `0`.

The solution must not use a `for` loop.

### Example

```text id="k6v3pn"
ToThePowerRecursive(2, 10)
// 1024
```

## Implementation

The solution uses recursive function calls, reducing the power by one on each call until reaching the base case.

Expected signature:

```go id="m8q2xr"
func ToThePowerRecursive(n int, power int) int
```
