# Factorial Recursive

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice recursion by solving a mathematical problem without using loops.

## Task

Create a recursive function named `FactorialRecursive` that calculates the factorial of a given integer.

The function should return `0` for negative values or when the result would overflow an `int`.

The solution must not use a `for` loop.

### Example

```text id="k4m8vz"
FactorialRecursive(5)
// 120
```

## Implementation

The solution uses recursion, with each function call calculating the factorial of the previous integer until reaching the base case.

Overflow is checked before performing multiplication.

Expected signature:

```go id="x7p3qn"
func FactorialRecursive(n int) int
```
