## To the Power Iterative

**Learning Objectives:**

* Gain proficiency in writing iterative functions to solve mathematical problems.
* Understand how to calculate the power of a number.

### Instructions

You're tasked with creating an iterative function that calculates the power of an integer `n` to the given power.

Handle negative powers by returning `0`.

#### Expected function signature

```go id="x6v3nb"
func ToThePowerIterative(n int, power int) int {

}
```

#### Usage

```go id="q8m2kd"
ToThePowerIterative(2, 10)
>> 1024
```
