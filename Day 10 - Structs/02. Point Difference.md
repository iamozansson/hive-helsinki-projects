# Point Difference

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice reading and manipulating data stored in structs.

## Task

Using the `Point` struct from the previous exercise, create a function named `PointDiff` that compares two points based on the sum of their `X` and `Y` coordinates.

The function should return the point with the greater coordinate sum. If the sums are equal, either point can be returned.

### Example

```text
PointDiff(
    Point{X: 2, Y: 3, Text: "A"},
    Point{X: 4, Y: 1, Text: "B"},
)
// Returns either point because both sums equal 5.
```

## Implementation

The solution calculates `X + Y` for both points and returns the point with the greater sum.

Expected signature:

```go
func PointDiff(p1, p2 Point) Point
```

* Reading struct fields
* Working with custom data types
* Comparing calculated values
* Conditional logic
* Function parameters and return values
