# Rectangle

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice working with multiple structs and using data from one struct to create another.

## Task

Create two structs:

`Coords`:

* `X` — int
* `Y` — int

`Rectangle`:

* `Width` — int
* `Height` — int
* `Area` — int
* `Perimeter` — int

Create a function named `GetRectangle` that takes the bottom-left and top-right coordinates and returns a `Rectangle` with all fields calculated.

### Example

```go id="r8w4kf"
min := Coords{X: 1, Y: 1}
max := Coords{X: 6, Y: 4}

GetRectangle(min, max)
// {5, 3, 15, 16}
```

## Implementation

The solution calculates the width and height from the difference between the corresponding coordinates, then uses them to calculate the area and perimeter.

Expected signature:

```go id="m2v7qx"
func GetRectangle(min, max Coords) Rectangle
```

## What I Practiced

* Defining multiple structs
* Reading struct fields
* Using one struct to populate another
* Calculating width and height
* Area and perimeter calculations
* Function parameters and return values
