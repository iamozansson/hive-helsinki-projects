## New Struct

**Learning Objectives:**

* Understand how to compose data structures.
* Creating data structures (constructors).

### Instructions

You'll need to compose a structure called `Point`, which will contain the following fields (in the exact order):

```text
X - float
Y - float
Text - string
```

This structure will represent text at a specific point (for example, on a graph or video game).

You will need to write a function that will return a newly created `struct` of this with fields filled from the parameters provided.
