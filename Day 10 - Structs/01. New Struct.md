# New Struct

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice creating structs, defining fields, and using constructors to create new data structures.

## Task

Create a `Point` struct containing the following fields in the exact order:

* `X` — float32
* `Y` — float32
* `Text` — string

Then create a function named `MakePoint` that returns a new `Point` using the provided parameters.

### Expected Signature

```go
type Point struct {
    X    float32
    Y    float32
    Text string
}

func MakePoint(x, y float32, text string) Point
```

## Implementation

The solution defines the `Point` struct and uses `MakePoint` as a constructor to initialize and return a new `Point` value.

## What I Practiced

* Structs
* Struct fields
* Creating custom data types
* Constructor functions
* Function parameters and return values
* Working with `float32` and `string`
