# Circle Result

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to apply struct creation, field manipulation, calculations, and constructor functions from the previous exercises.

## Task

Create a `Circle` struct containing the following fields in the exact order:

* `Radius` — float32
* `Diameter` — float32
* `Area` — float32
* `Perimeter` — float32

Create a function named `GetCircle` that takes the radius and returns a `Circle` with all fields calculated.

For π, the value `3.14` must be used.

### Formulas

* Diameter = `2 × Radius`
* Area = `π × Radius²`
* Perimeter = `2 × π × Radius`

### Example

```text id="v4m2pk"
GetCircle(5)
// Circle{Radius: 5, Diameter: 10, Area: 78.5, Perimeter: 31.4}
```

## Implementation

The solution creates a `Circle` struct and calculates its diameter, area, and perimeter from the provided radius using `3.14` as π.

Expected signature:

```go id="x2j7pf"
func GetCircle(r float32) Circle
```
