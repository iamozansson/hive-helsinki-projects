## Winner

**Learning Objectives:**

* Define structures with mixed types including slices.
* Read and compute values from structure fields.

### Instructions

Create a structure called `Contestant` with the following fields (in the exact order):

```text
Name   - string
Scores - slice of integers
```

Write a function that takes two `Contestant` structures and returns the name of the one with the higher total score.

If the totals are equal, return either name.

#### Expected function/structure signature

```go id="k4m8sx"
type ??? // Fill this in

func GetWinner(c1, c2 Contestant) string {

}
```

#### Usage

```go id="q7v2pn"
c1 := Contestant{Name: "Alice", Scores: []int{9, 8, 10}}  // total: 27
c2 := Contestant{Name: "Bob", Scores: []int{7, 6, 7}}      // total: 20

GetWinner(c1, c2)
>> "Alice"
```
