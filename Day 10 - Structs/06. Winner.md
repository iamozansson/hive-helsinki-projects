# Winner

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice defining structs with different data types and calculating values from struct fields.

## Task

Create a `Contestant` struct containing:

* `Name` — string
* `Scores` — []int

Create a function named `GetWinner` that takes two contestants and returns the name of the contestant with the higher total score.

If the totals are equal, either name can be returned.

### Example

```go id="p6z1kc"
c1 := Contestant{Name: "Alice", Scores: []int{9, 8, 10}}
c2 := Contestant{Name: "Bob", Scores: []int{7, 6, 7}}

GetWinner(c1, c2)
// "Alice"
```

## Implementation

The solution calculates the total score for each contestant by iterating over their `Scores` slices, then returns the name of the contestant with the higher total.

Expected signature:

```go id="t3q8vn"
func GetWinner(c1, c2 Contestant) string
```
