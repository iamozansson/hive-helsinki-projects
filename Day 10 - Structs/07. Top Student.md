## Top Student

### Instructions

Create a structure called `Student` with the following fields (in the exact order):

```text
Name   - string
Grades - slice of integers
```

Write a function that takes a slice of `Student` structures and returns the one with the highest average grade.

If multiple students share the highest average, return any of them. If the slice is empty, return a zero-value `Student`.

#### Expected function/structure signature

```go
type ??? // Fill this in

func TopStudent(students []Student) Student {

}
```

#### Usage

```go
students := []Student{
    {Name: "Alice", Grades: []int{80, 90, 85}},
    {Name: "Bob", Grades: []int{95, 92, 98}},
    {Name: "Carol", Grades: []int{70, 75, 72}},
}

TopStudent(students)
>> {Bob [95 92 98]}

TopStudent([]Student{})
>> { []}
```
