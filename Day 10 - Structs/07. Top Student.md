# Top Student

A Go exercise based on a programming task from my Hive Helsinki sprint curriculum.

## Objective

The goal of this exercise was to practice working with slices of structs and calculating average values from struct fields.

## Task

Create a `Student` struct containing:

* `Name` — string
* `Grades` — []int

Create a function named `TopStudent` that takes a slice of students and returns the student with the highest average grade.

If multiple students have the same highest average, any of them can be returned.

If the input slice is empty, return a zero-value `Student`.

### Example

```go id="c8m4zt"
students := []Student{
    {Name: "Alice", Grades: []int{80, 90, 85}},
    {Name: "Bob", Grades: []int{95, 92, 98}},
    {Name: "Carol", Grades: []int{70, 75, 72}},
}

TopStudent(students)
// {Bob [95 92 98]}

TopStudent([]Student{})
// { []}
```

## Implementation

The solution iterates through the students, calculates the average grade for each student, and keeps track of the student with the highest average.

Expected signature:

```go id="v2n7kp"
func TopStudent(students []Student) Student
```
