# Point Text

A Go exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice reading data from structs, modifying struct fields, and returning a new struct.

## Task

Using the `Point` struct from the previous exercises, create a function named `PointText` that returns a new `Point`.

The returned point should keep the same `X` and `Y` coordinates, but its `Text` field should be formatted as:

```text
"Text at (X, Y)"
```

### Example

```text
PointText(Point{X: 2, Y: 3, Text: "Hello"})
// Point{X: 2, Y: 3, Text: "Text at (2, 3)"}
```

## Implementation

The solution keeps the original coordinates and creates a new `Point` with the `Text` field formatted using `fmt`.

Expected signature:

```go
func PointText(p Point) Point
```

## What I Practiced

* Reading struct fields
* Modifying struct data
* Creating new structs
* String formatting with `fmt`
* Function parameters and return values
