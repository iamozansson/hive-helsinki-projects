# Loop Text

A Bash scripting exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice using command-line arguments, variables, conditional logic, comparisons, and loops in Bash.

## Task

Create a shell script named `loop.sh` that:

* Takes the number of loop iterations from the first command-line argument
* Prints the current loop number on each iteration
* Limits the number of iterations to a maximum of 100

For example:

```bash
./loop.sh 5
```

Output:

```text
This is loop number 1
This is loop number 2
This is loop number 3
This is loop number 4
This is loop number 5
```

## Implementation

The solution is implemented in `loop.sh`.
