# Find Your Way

A command-line exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice searching through directory structures using patterns and wildcards.

## Task

Create a shell script named `find.sh` that searches the current directory and its subdirectories for:

* Files or directories starting with `a`
* Files ending with `z`
* Files starting with `z` and ending with `a`

The search is performed using the `find` command and appropriate filename patterns.

## Implementation

The solution is implemented in `find.sh`.

Run the script with:

```bash id="xk1n4y"
./find.sh
```

## What I Practiced

* Searching directory structures with `find`
* Filename patterns and wildcards
* Regular expression concepts
* Shell command options
* Combining search conditions
* Using `man` pages to understand command syntax
