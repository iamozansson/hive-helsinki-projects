# Needles In a Haystack

A command-line exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice searching text in files, using basic regular expressions, and combining commands with pipes.

## Task

Search a text file for lines containing the word `not` and count how many matching lines there are.

The solution uses `grep` to find the matching lines and `wc` to count them.

## Implementation

The command used to solve the task is stored in the corresponding shell script.

Run the script with:

```bash
bash needlesInAHaystack.sh
```

The script outputs the number of lines containing the word `not`.

## What I Practiced

* Searching text with `grep`
* Basic regular expressions
* Counting lines with `wc`
* Piping the output of one command into another
* Using `man` pages to understand command options
