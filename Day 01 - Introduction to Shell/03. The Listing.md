# The Listing

A command-line exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice using command-line options to customize directory listings and sort files based on their access time.

## Task

Create a shell script named `theListing.sh` that lists the contents of the current directory according to specific requirements:

* Include non-hidden files and directories
* Exclude `.` and `..`
* Use commas and spaces as separators
* Sort entries by access time, with the most recently accessed first
* Append `/` to directory names

The solution uses a single command with appropriate `ls` options.

## Implementation

The required command is stored in `theListing.sh`.

Run the script with:

```bash
bash theListing.sh
```

## What I Practiced

* `ls` command and command-line options
* Directory listing
* Sorting files by access time
* Formatting command output
* Using `man` pages to understand command options
