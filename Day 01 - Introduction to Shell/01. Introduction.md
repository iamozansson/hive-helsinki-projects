# Introduction

A small Bash and Git exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice the basics of working with a Git repository and creating a simple shell script.

## Task

Create a Bash script named `introduction.sh` that prints:

```text
Hello World!
```

The exercise also introduced the basic Git workflow of creating a repository, committing changes, and pushing them to a remote repository.

## Implementation

The solution is implemented in `introduction.sh`.

The script prints the requested message when executed:

```bash
bash introduction.sh
```

Output:

```text
Hello World!
```

## What I Practiced

* Bash scripting basics
* Linux command line
* Git fundamentals
* Creating and managing a repository
* Committing and pushing changes
