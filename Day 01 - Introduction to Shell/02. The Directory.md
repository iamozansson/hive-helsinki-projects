# The Directory

A Linux command-line exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice navigating directories, reading file contents from the command line, and identifying the current working directory.

## Task

Navigate through a directory structure to find a specific file, display its contents in the terminal, and print the directory in which the file is located.

The commands used to complete the task were then documented in `theDirectory.sh`.

## Implementation

The solution uses basic Linux command-line tools to:

* Navigate between directories
* Locate and read the target file
* Print the current working directory

The commands used for the solution are stored in `theDirectory.sh`.

## How to Run

Run the script with:

```bash
bash theDirectory.sh
```

## What I Practiced

* Navigating directories with `cd`
* Reading file contents from the terminal
* Finding files in a directory structure
* Using `pwd` to identify the current working directory
* Working with the Linux command line
