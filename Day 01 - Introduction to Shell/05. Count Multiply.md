# Count Multiply

A Bash scripting exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice using variables, performing arithmetic operations, and formatting output in a shell script.

## Task

Create a shell script named `count.sh` that:

* Counts all files and directories in the current directory and its subdirectories
* Multiplies the total by 5
* Prints the result using the required text format and control characters

The exercise focuses on combining command-line tools with basic Bash scripting.

## Implementation

The solution is implemented in `count.sh`.

Run the script with:

```bash
./count.sh
```

Example output:

```text
Total files * 5: 25
```

## What I Practiced

* Bash variables
* Arithmetic operations
* Counting files and directories
* Command substitution
* `printf` formatting
* Escape sequences and control characters
* Basic shell scripting
