# Make, Copy & Remove

A Bash scripting exercise completed during my Hive Helsinki programming sprint.

## Objective

The goal of this exercise was to practice creating, copying, moving, and removing files and directories while working with special characters in the shell.

## Task

Create a shell script named `files.sh` that:

* Creates files with special characters in their names
* Creates a directory with a special-character name
* Copies a file into the directory
* Uses a conditional based on the `MOVE_A` environment variable to either move or remove a file

The script handles different values of `MOVE_A`:

* `yes` → move the file
* `no` → remove the file
* Any other value or unset → leave the file unchanged

## Implementation

The solution is implemented in `files.sh`.

Run the script with:

```bash
./files.sh
```

The behavior can be controlled using the `MOVE_A` environment variable.
